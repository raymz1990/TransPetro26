### 1. O que a prova cobra

A prova de Língua Inglesa tem **10 questões** (edital; matriz de Conhecimentos Gerais), com **textos escritos** e questões de **compreensão** e de **itens gramaticais relevantes** para o sentido (`02`). O edital **não informa** a distribuição entre os dois itens. Não há questões de Língua Inglesa catalogadas no projeto; **nenhuma tendência da banca é afirmada**. Os textos tendem a ser **jornalísticos ou técnicos** (artigos de imprensa, relatórios, textos corporativos), tema a confirmar em provas reais.

### 2. Estratégias de leitura (de memória)

| Estratégia | Como | Quando |
|---|---|---|
| **Pré-leitura** | Título, subtítulo, legendas, fonte, data; **prever** o assunto | Antes de ler |
| ***Skimming*** | Leitura **rápida** do todo (primeiro e último parágrafos, **primeira frase** de cada parágrafo) para a **ideia geral** | Questões de ideia central |
| ***Scanning*** | Busca **pontual** de dados (nomes, números, datas) | Questões de detalhe |
| **Inferência** | Deduzir o sentido por contexto, morfologia e conectivos | Vocabulário desconhecido |
| **Leitura intensiva** | Leitura cuidadosa do trecho a que a questão se refere | Questões de interpretação |
| **Palavras-chave** | Substantivos, verbos e números principais | Sempre |
| **Marcadores do texto** | *However, therefore, for example, in addition* | Relações lógicas (seção 5) |

**Procedimento:** (1) leia o **enunciado e as perguntas** antes do texto; (2) faça *skimming*; (3) leia o texto atentamente marcando palavras-chave; (4) volte ao trecho para cada questão (*scanning*); (5) **elimine** alternativas que **contradizem** o texto, **extrapolam** ou usam palavras do texto com **sentido alterado**.

### 3. Vocabulário

#### 3.1 Cognatos

Palavras parecidas em inglês e português, com mesma origem e sentido: *important, information, company, problem, energy, system, industry, resource, strategy, project, risk, security*. Útil para a leitura.

#### 3.2 Falsos cognatos (*false friends*) — ver a revisão no cabeçalho; sentidos de memória, exceto onde indicado

| Palavra em inglês | Parece com | **Significa** |
|---|---|---|
| **parents** | parentes | **pais** (mãe e pai); *relatives* = parentes (**confirmado em Wikipedia**) |
| **actually** | atualmente | **na verdade, de fato**; *currently/nowadays* = atualmente |
| **eventually** | eventualmente | **por fim, no final das contas**; *occasionally* = eventualmente |
| **library** | livraria | **biblioteca**; *bookstore* = livraria |
| **attend** | atender | **assistir, comparecer**; *to answer/serve* = atender |
| **pretend** | pretender | **fingir**; *to intend* = pretender |
| **realize** | realizar | **perceber, dar-se conta**; *to carry out* = realizar |
| **push** | puxar | **empurrar**; *pull* = puxar |
| **exquisite** | esquisito | **requintado, refinado**; *odd/weird* = esquisito |
| **college** | colégio | **faculdade**; *high school* = colégio |
| **argument** | argumento | **discussão, briga** (também argumento); *reasoning* |
| **resume** | resumir | **retomar**; *summarize* = resumir; *résumé* = currículo |
| **sensible** | sensível | **sensato, razoável**; *sensitive* = sensível |
| **support** | suportar | **apoiar, sustentar**; *to tolerate* = suportar |
| **costume** | costume | **fantasia, traje**; *habit/custom* = costume |
| **novel** | novela | **romance**; *soap opera* = novela |
| **lunch** | lanche | **almoço**; *snack* = lanche |
| **fabric** | fábrica | **tecido**; *factory* = fábrica |
| **injury** | injúria | **lesão, ferimento**; *insult* = injúria |
| **comprehensive** | compreensivo | **abrangente**; *understanding* = compreensivo |
| **assume** | assumir (cargo) | **supor**, também assumir |
| **intend** | entender | **pretender**; *to understand* = entender |
| **hazard** | azar | **perigo, risco**; *bad luck* = azar |
| **grip** | gripe | **aperto, pegada**; *flu* = gripe |

Contexto decide: *actually* aparece muito em provas com sentido de "na verdade".

#### 3.3 Formação de palavras (afixos úteis)

| Afixo | Sentido | Exemplos |
|---|---|---|
| **un-, in-, im-, il-, ir-, dis-, mis-, non-** | negação, oposto | unsafe, incomplete, impossible, illegal, dishonest, misunderstand |
| **re-** | de novo | rebuild, review |
| **pre-, post-** | antes, depois | preview, postpone |
| **over-, under-** | excesso, falta | overload, underestimate |
| **-er, -or, -ist, -ian** | agente | manager, operator, scientist |
| **-ness, -ity, -ment, -tion, -ship** | substantivo | happiness, security, development, information, partnership |
| **-ful, -less** | com / sem | useful, harmless |
| **-able, -ible, -ive, -al, -ous** | adjetivo | reliable, effective, global, dangerous |
| **-ly** | advérbio | quickly |
| **-ize/-ise, -ify, -en** | verbo | modernize, simplify, strengthen |

#### 3.4 *Phrasal verbs*, expressões e colocações

Verbo + partícula com **sentido próprio**: *carry out* (executar), *set up* (instalar, estabelecer), *look into* (investigar), *rule out* (descartar), *turn down* (recusar), *point out* (apontar), *go ahead* (prosseguir), *bring about* (provocar), *deal with* (lidar com), *cut back on* (reduzir), *break down* (quebrar/analisar), *find out* (descobrir), *run out of* (esgotar). Colocações (*make a decision, take a risk, do research, reach an agreement*). **Dica:** em textos técnicos, procure o **verbo único** equivalente (*carry out = perform*).

### 4. Tipos de questão e estratégia

| Tipo | Estratégia |
|---|---|
| **Main idea / purpose** | Procure a tese; evite alternativas **específicas demais** ou **amplas demais** |
| **Detail (explicit)** | *Scanning*; atenção a **troca de termos** (*all/some*, *always/sometimes*, *increase/decrease*) |
| **Inference** | Conclusão **necessária** do texto; evite **extrapolar** |
| **Reference** | Que palavra o pronome (*it, they, this, which*) retoma? |
| **Vocabulary in context** | Substitua pela alternativa na frase; confira **classe gramatical** |
| **Author's tone/attitude** | Adjetivos e advérbios avaliativos; ironia; *critical, optimistic, neutral* |
| **True/false/not mentioned** | Distinguir **ausente** de **contradito** |
| **Sentence completion/paraphrase** | Preserve sentido e relação lógica |
| **Text structure / organization** | Problema–solução, causa–efeito, comparação, cronologia |

**Armadilhas:** alternativas **verdadeiras no mundo real**, mas **ausentes do texto**; **paráfrase** com sentido alterado; **números e datas** trocados; **absolutos** (*never, always, only*); uso de **cognatos enganosos**.

### 5. Marcadores do discurso (*linking words*)

| Relação | Marcadores |
|---|---|
| **Adição** | and, also, moreover, furthermore, in addition, besides |
| **Contraste** | but, however, yet, nevertheless, on the other hand, whereas, while, in contrast |
| **Concessão** | although, though, even though, despite, in spite of |
| **Causa** | because, since, as, due to, owing to, because of |
| **Consequência / resultado** | so, therefore, thus, as a result, consequently, hence |
| **Finalidade** | to, in order to, so that, so as to |
| **Condição** | if, unless, provided that, as long as, otherwise |
| **Exemplo** | for example, for instance, such as, namely |
| **Sequência** | first, then, next, finally, afterwards, meanwhile |
| **Ênfase / retificação** | indeed, in fact, actually, in other words |
| **Conclusão** | in conclusion, to sum up, overall |

**Confusão frequente:** *despite/in spite of* + **substantivo ou -ing** (não + oração); *although* + **oração**; *because* + oração × *because of* + substantivo; *since* (causa **ou** tempo: "desde"); *while* (tempo **ou** contraste); *as* (causa, tempo, comparação).

### 6. Referência e coesão

Pronomes (*it, they, this, that, these, those, which, who*), **retomada** por sinônimos, **elipse** (*The first plan failed; the second [plan] succeeded*), **substituição** (*one, ones, do so*), conectivos. **Antecedente de *which*:** pode retomar **uma oração inteira** ("The company cut costs, **which** pleased investors").

### 7. Tom, registro e gêneros

**Formal × informal** (contrações, *phrasal verbs*, gírias); **gêneros:** notícia, artigo de opinião, relatório, e-mail corporativo, comunicado, manual. **Tom do autor:** neutro, crítico, irônico, otimista. **Hedges** (*may, might, seems, is likely to*) indicam **possibilidade**, não certeza.

### 8. Números, datas e quantidades

*Percent, billion* (= bilhão, 10⁹), *million*, *trillion* (trilhão), *dozen*; decimais com **ponto** (*3.5* = 3,5); milhar com **vírgula** (*1,000*); datas (*June 5th* / *5 June*); *half, a third, twice as much, three times as many*; comparações (*the largest, the second-highest*). **Atenção:** *billion* = **bilhão** (10⁹) e *trillion* = **trilhão** (10¹²).

### 9. Exemplo (didático)

Texto: "*Although oil production rose by 5%, the company reported lower profits because of falling prices. Analysts, however, expect a recovery.*"
- **Ideia central:** produção sobe, lucro cai por causa dos preços; expectativa de recuperação.
- **Detail:** produção +5%.
- **Inference:** os preços, não a produção, explicam o lucro menor.
- **Linking words:** *although* (concessão), *because of* (causa + substantivo), *however* (contraste).
- **Armadilha:** "A produção caiu" (contradito) × "Os analistas garantem recuperação" (*expect* ≠ garantir).

### 10. Comparações conceituais

| A | B | Diferença |
|---|---|---|
| *Skimming* | *Scanning* | Ideia geral × dado específico |
| Cognato | Falso cognato | Mesmo sentido × sentido diferente |
| Inferência | Extrapolação | Decorre do texto × vai além |
| *Because* | *Because of* | + oração × + substantivo |
| *Although* | *Despite* | + oração × + substantivo/-ing |
| *Expect* | *Wait*/ *Await* | Esperar (prever) × esperar (aguardar) |

- Leia **cada palavra-chave** da alternativa (absolutos, números, conectivos).
- Cuidado com **falsos cognatos** e *phrasal verbs*.

### 1. Tempos verbais e seu sentido

| Tempo | Forma | Sentido | Exemplo |
|---|---|---|---|
| **Simple present** | V / V-s | Hábito, fato, verdade geral | "The plant **operates** 24 hours." |
| **Present continuous** | am/is/are + V-ing | Ação **em curso** ou plano próximo | "The team **is testing** a new valve." |
| **Simple past** | V-ed / irregular | Ação **concluída** no passado | "They **signed** the contract in May." |
| **Past continuous** | was/were + V-ing | Ação em curso no passado | "They **were inspecting** when the alarm rang." |
| **Present perfect** | have/has + particípio | Ação passada com **relevância atual**; experiência; **duração até agora** (*for, since*) | "We **have completed** the audit." "He **has worked** here **since** 2020." |
| **Present perfect continuous** | have/has been + V-ing | Ação **iniciada no passado e ainda em curso** (ênfase na duração) | "She **has been working** for two hours." |
| **Past perfect** | had + particípio | Ação **anterior** a outra no passado | "The shift **had ended** when the report arrived." |
| **Simple future** | will + V | Previsão, decisão no momento | "It **will rain**." |
| **Be going to** | am/is/are going to + V | Plano, intenção, evidência | "They **are going to** upgrade the system." |
| **Future continuous / perfect** | will be V-ing / will have + particípio | Em curso / concluída até certo momento | "By June we **will have finished**." |

**Contrastes-chave:** **simple past × present perfect**: o passado define **quando** (*yesterday, in 2019, ago*), o perfect liga ao **presente** (*already, yet, just, ever, never, so far, recently*). **For** (período) × **since** (ponto inicial). **Used to + V** (hábito passado, já não ocorre) × **be used to + V-ing** (estar acostumado).

### 2. Verbos modais

| Modal | Sentido | Exemplo |
|---|---|---|
| **can / could** | Capacidade, possibilidade, permissão; *could* = passado ou polidez | "The system **can** process..." |
| **may / might** | Possibilidade (*might* = mais remota); permissão (*may*) | "Prices **may** rise." |
| **must** | Obrigação forte; **dedução** forte | "You **must** report..." "He **must** be tired." |
| **have to** | Obrigação **externa** | "We **have to** comply." |
| **should / ought to** | Conselho, recomendação | "You **should** back up the data." |
| **will / would** | Futuro; **hábito passado**; hipótese; polidez | "I **would** like..." |
| **shall** | Oferta/sugestão; textos legais ("shall" = obrigação) | "The supplier **shall** deliver..." |
| **needn't / don't have to** | **Ausência** de obrigação | "You **don't have to** attend." |
| **mustn't** | **Proibição** | "You **mustn't** smoke here." |
| **Perfect modals** | Passado: *should have* (crítica), *could have* (possibilidade não realizada), *must have* (dedução), *might have* | "He **should have called**." |

**Atenção:** *must not* (proibição) ≠ *don't have to* (não obrigatório); *may/might* indicam **incerteza** (não afirmam o fato).

### 3. Voz passiva

**Forma:** *be* (no tempo) + **particípio passado**. Usada quando o **agente** é desconhecido, óbvio ou irrelevante (comum em textos técnicos).

| Tempo | Exemplo |
|---|---|
| Present simple | "Data **is stored** in the cloud." |
| Past simple | "The valve **was replaced**." |
| Present perfect | "The report **has been approved**." |
| Future | "The plan **will be reviewed**." |
| Modal | "It **must be tested**." |
| Continuous | "The system **is being updated**." |

**Agente:** *by* ("written **by** the team"). **Interpretação:** em "The contract **was signed**", o foco é o contrato. **Verbos causativos:** *have/get something done* ("We **had** the pipeline **inspected**" = alguém inspecionou para nós).

### 4. Condicionais

| Tipo | Forma | Sentido | Exemplo |
|---|---|---|---|
| **Zero** | if + present, present | **Fatos gerais** | "If water **reaches** 100 °C, it **boils**." |
| **1ª** | if + present, **will** + V | **Possibilidade real** no futuro | "If it **rains**, we **will cancel**." |
| **2ª** | if + past, **would** + V | **Hipótese presente/futura improvável** | "If I **had** more time, I **would** study." |
| **3ª** | if + **past perfect**, **would have** + particípio | **Hipótese passada irreal** (não aconteceu) | "If they **had tested**, they **would have found**..." |
| **Mista** | if + past perfect, would + V | Passado → presente | "If he **had listened**, he **would be** safe." |

**Outros:** ***unless*** (= *if not*), ***provided/as long as*** (se, desde que), ***in case*** (para o caso de), **inversão formal** ("**Had** they tested..." = if they had tested). **Wish:** "I **wish** I **were**..." (desejo irreal).

### 5. Orações relativas

| Pronome | Uso | Exemplo |
|---|---|---|
| **who** | Pessoas (sujeito) | "The engineer **who** designed it..." |
| **whom** | Pessoas (objeto, formal) | "The man **whom** I met" |
| **which** | Coisas | "The valve **which** failed..." |
| **that** | Pessoas ou coisas (**defining**) | "The system **that** we use..." |
| **whose** | Posse | "A company **whose** profits rose" |
| **where / when / why** | Lugar / tempo / razão | "The site **where** it happened" |

**Defining (restritiva)**: sem vírgulas, **that** ou **which**: "The reports **that** were late..." (só os atrasados). **Non-defining (explicativa)**: com vírgulas, **which/who** (não *that*): "The reports, **which** were late, ..." (todos eram). **Which** pode retomar **toda a oração** anterior. **Omissão** do pronome objeto: "The report (**that**) I read".

### 6. Discurso indireto (*reported speech*)

| Discurso direto | Indireto (verbo introdutor no passado) |
|---|---|
| "I **am** tired." | He said (that) he **was** tired. |
| "I **work** here." | She said she **worked** here. |
| "I **have finished**." | He said he **had finished**. |
| "I **will** call." | She said she **would** call. |
| "I **can** help." | He said he **could** help. |
| "Did you sign?" | She asked **if/whether** I **had signed**. |
| "Don't touch it." | He told me **not to touch** it. |

**Mudanças:** pronomes, advérbios (*here → there*, *now → then*, *today → that day*, *tomorrow → the next day*), tempos retrocedem um degrau. **Nuance:** o recuo de tempos **não é obrigatório** quando a situação relatada ainda é válida ("She said that she **lives** in Rio" é possível); em prova, a alternativa que mantém o presente nesses casos pode estar correta. **Verbos de relato:** *say, tell (+ pessoa), ask, claim, state, announce, warn, suggest, admit, deny*.

### 7. Comparativos e superlativos

**Comparativo:** curtos (*-er than*: *taller than*), longos (*more ... than*), **irregulares** (*good → better → best*; *bad → worse → worst*; *far → farther/further*). **Superlativo:** *the -est / the most*. **Igualdade:** *as ... as*; **desigualdade:** *not as ... as*. **Proporção:** *the more..., the more...* ("**The higher** the risk, **the greater** the cost"). **Comparação duplicada:** *increasingly, more and more*. **Cuidado:** *as ... as* **≠** *than*.

### 8. Preposições, *phrasal verbs* e expressões de tempo/lugar

| Preposição | Uso | Exemplos |
|---|---|---|
| **in / on / at** (tempo) | in (meses, anos, séculos); on (dias, datas); at (horas, momentos) | in 2026, on Monday, at 5 p.m. |
| **in / on / at** (lugar) | in (dentro), on (sobre/em superfície), at (ponto) | in the tank, on the deck, at the port |
| **for / since / during / by / until** | for (duração), since (início), during (ao longo de), by (até/prazo), until (até; continuidade) | by Friday (prazo) × until Friday (até lá) |
| **between / among** | duas / mais de duas | — |
| **about / on** | sobre (assunto) | a report **on** safety |
| **despite / in spite of** | apesar de | + substantivo/-ing |
| **Dependentes** | depend **on**, consist **of**, result **in/from**, responsible **for**, aware **of**, interested **in**, different **from** | — |

### 9. Substantivos, artigos e quantificadores

- **Contáveis × incontáveis:** *information, advice, equipment, research, news, progress* são **incontáveis** (sem plural; *much, a little*); contáveis: *many, few, a number of*. *Few/little* (pouco, **negativo**) × *a few/a little* (alguns/um pouco, **positivo**).
- **Artigos:** *a/an* (primeira menção, genérico), *the* (específico, conhecido, único), **ausência** (plurais e incontáveis genéricos): "**Safety** is important."
- **Genitivo:** *the company's policy*, *the policy of the company*.
- **Sequências de substantivos** (*noun phrases*): o **último** é o núcleo; os anteriores modificam: "**gas pipeline safety report**" = relatório de segurança de gasodutos. Leia **da direita para a esquerda**.

### 10. Pronomes

- **Pessoais (sujeito/objeto):** *I/me, he/him, she/her, it, we/us, they/them*.
- **Possessivos:** adjetivos (*my, his, its, our, their*) × pronomes (*mine, his, ours, theirs*). **Atenção: *its* (possessivo) × *it's* (= it is/has)**; *their/there/they're*.
- **Reflexivos e ênfase:** *himself, themselves* ("The system **itself** failed").
- **Demonstrativos:** *this/these* (perto), *that/those* (longe; ou retoma).
- **Indefinidos:** *some/any* (afirmativa/negativa e interrogativa), *no/none*, *every-, some-, any-, no-* + *one/body/thing/where*, *either/neither*, *both*, *each/every*.
- **Recíprocos:** *each other, one another*.

### 11. Outras estruturas que alteram o sentido

| Estrutura | Observação |
|---|---|
| **Gerúndio × infinitivo** | *stop doing* (parar de) × *stop to do* (parar para); *remember doing* (lembrar do que fez) × *remember to do* (lembrar de fazer) |
| **Perguntas e inversão** | *Never had they seen...* (ênfase negativa: inversão) |
| **Negativas** | *not only... but also*; *neither... nor* |
| **Causativos** | *make/let/have someone do*; *get someone to do* |
| **Quantidade e comparação com *too/enough*** | *too* (excesso: "too hot"), *enough* (suficiência: "hot enough"), *so... that / such... that* |
| **Particípios como adjetivos** | *-ed* (sentimento: *bored*) × *-ing* (causa: *boring*) |
| **Conectores** | ver `01` |
| **Contrações** | *it's, don't, they've, I'd* (= *I would/I had*, depende do contexto) |

### 12. Exemplo (didático)

"*If the pipeline **had been inspected** earlier, the leak **might have been prevented**, which **would have saved** millions.*" — 3ª condicional (hipótese **irreal** do passado), **voz passiva**, *might have* (possibilidade não ocorrida), *which* retoma **toda a oração**. Sentido: **não** foi inspecionado e **não** foi evitado.

### 13. Comparações conceituais

| A | B | Diferença |
|---|---|---|
| Simple past | Present perfect | Passado definido × ligação com o presente |
| *Must* | *Have to* | Obrigação (ou dedução) do falante × externa |
| *Mustn't* | *Don't have to* | Proibido × desnecessário |
| *May/might* | *Will* | Possibilidade × certeza/previsão |
| Condicional 2 | Condicional 3 | Hipótese presente × passado irreal |
| *That* (defining) | *Which* (non-defining) | Restringe (sem vírgula) × acrescenta (com vírgulas) |
| *For* | *Since* | Duração × ponto inicial |
| *Few* | *A few* | Pouco (negativo) × alguns (positivo) |
| *Its* | *It's* | Possessivo × *it is/has* |
