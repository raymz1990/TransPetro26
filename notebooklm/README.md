# NotebookLM — fontes do projeto

Arquivos **gerados**: edite `conteudo/` ou `banco-questoes/` e rode `python tools/build_notebooklm.py`.

Sugestão: um notebook por módulo, com `fontes/Mxx_*_Completo.md` e, para treino, `fontes/questoes/Mxx_*_Questoes_sem_gabarito.md`, mantendo o gabarito comentado fora até terminar. Prompts em `prompts/`.

O NotebookLM é ferramenta complementar: não valida conteúdo nem gabarito. Ver `fontes/00-indice-fontes.md`.
