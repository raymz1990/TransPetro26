# Regência Verbal e Nominal

**Disciplina:** Língua Portuguesa (Conhecimentos Gerais — Fase 2)
**Texto oficial (Anexo IV, Conhecimentos Básicos):** 10 "Regência verbal e nominal."
**Escopo:** A. Crase: `11`; concordância: `09`.
**Status:** `VALIDADO` (aprovado pelo usuário em 2026-10-31, com ressalvas: interpretação dos subtópicos de itens de redação genérica; gramática e ortografia em grande parte de memória, conforme `docs/qualidade/relatorio-producao-gerais.md`). Conteúdo de memória; **não verificado em fonte primária** nesta etapa (a página da Wikipedia consultada traz só a definição geral).

**Objetivos de aprendizagem.** (1) Definir regência e transitividade; (2) identificar verbos com mais de uma regência e mudança de sentido; (3) aplicar a preposição correta; (4) usar a regência nominal; (5) combinar regência com pronomes relativos e crase.

---

## 1. Conceitos

**Regência** é a relação de **dependência** entre um termo **regente** (verbo ou nome) e seu **complemento** (**regido**), com ou sem **preposição**. **Regência verbal:** verbo + complemento. **Regência nominal:** nome (substantivo, adjetivo, advérbio) + **complemento nominal** (sempre com preposição).

### 1.1 Transitividade verbal

| Tipo | Complemento | Exemplo |
|---|---|---|
| **Intransitivo (VI)** | Nenhum | "O trem **chegou**." |
| **Transitivo direto (VTD)** | **Sem preposição** (objeto direto) | "Ele **comprou** o livro." |
| **Transitivo indireto (VTI)** | **Com preposição** (objeto indireto) | "Ele **precisa** de ajuda." |
| **Transitivo direto e indireto (VTDI)** | Objeto direto + indireto | "Entreguei o relatório **ao** gerente." |
| **De ligação (VL)** | Predicativo | "Ele **está** cansado." |

O **mesmo verbo** pode mudar de transitividade com **mudança de sentido**.

## 2. Regência verbal: verbos de alta incidência (de memória)

| Verbo | Regência e sentido | Exemplo |
|---|---|---|
| **Assistir** | **VTI (a)**: ver, presenciar | "Assisti **ao** filme." |
| | **VTD**: ajudar, prestar assistência | "O médico **assistiu** o paciente." |
| | **VTI (a)**: caber, pertencer (direito) | "O direito **assiste** ao trabalhador." |
| **Aspirar** | **VTD**: inalar | "Aspirou o ar puro." |
| | **VTI (a)**: desejar, almejar | "Aspira **a** um cargo." |
| **Visar** | **VTD**: mirar; dar visto | "Visou o alvo/o cheque." |
| | **VTI (a)**: ter por objetivo | "Visa **ao** lucro." (ou "visa lucro": VTD admitido) |
| **Preferir** | **VTDI**: *preferir X a Y* (sem *do que*, sem *mais*) | "Prefiro café **a** chá." |
| **Obedecer / desobedecer** | **VTI (a)** | "Obedece **às** regras." |
| **Responder** | **VTI (a)** | "Respondeu **ao** e-mail." |
| **Simpatizar / antipatizar** | **VTI (com)** | "Simpatizo **com** ele." |
| **Aludir, referir-se** | **VTI (a)** | "Referiu-se **ao** projeto." |
| **Agradar** (ser agradável) | **VTI (a)** | "O filme agradou **ao** público." |
| **Agradar** (acariciar) | **VTD** | "Agradou o cão." |
| **Perdoar** | **VTDI** (perdoar algo a alguém) | "Perdoou a dívida **ao** devedor." |
| **Pagar** | **VTDI**; VTI (a) com pessoa | "Pagou a conta **ao** fornecedor." "Pagou **ao** fornecedor." |
| **Informar, avisar, comunicar, cientificar** | **VTDI**: *informar algo a alguém* ou *alguém de algo* | "Informou **o prazo** aos clientes." / "Informou **os clientes** do prazo." |
| **Chegar, ir, voltar** | **VI** com **a** (destino): "Chegou **a** São Paulo", "Foi **ao** banco" (**não** "em") | "Cheguei **a** casa." |
| **Morar, residir, situar-se** | **em** | "Mora **em** Niterói." |
| **Implicar** | **VTD**: acarretar | "A decisão implica **riscos**." |
| | **VTI (com)**: ter implicância | "Implica **com** o colega." |
| **Esquecer / lembrar** | **VTD**: "esqueceu o livro"; **pronominal (VTI de)**: "esqueceu-se **do** livro" | "Lembrou-se **do** prazo." |
| **Namorar** | **VTD** | "Namora a vizinha." |
| **Custar** (ser difícil) | **VTI (a)**, sujeito = oração/infinitivo | "Custou-**me** aceitar." |
| **Proceder** (ter fundamento) | **VI** | "A acusação **procede**." |
| | **VTI (a)** (iniciar): "Procedeu **ao** exame." | — |
| **Atender** | **VTD** ou VTI (a) | "Atendeu o cliente." / "Atendeu **ao** pedido." |
| **Ir / vir / chegar** | **a** (destino) × **de** (origem) | "Vem **de** casa." |
| **Chamar** | **VTD**: convocar; **VTD/VTI (por)**: nomear | "Chamou o gerente." "Chamam-no **de**/**por** doutor." |

**Regra de ouro com relativos:** a **preposição do verbo** vai **antes do relativo**: "O filme **a que** assisti" (assistir **a**); "A empresa **de que** preciso" (precisar **de**); "A cidade **para onde** vou"; "O sistema **com o qual** trabalho."

### 2.1 Preposição errada (erros frequentes)

| Incorreto | Correto |
|---|---|
| "Assistiu **o** jogo." | "Assistiu **ao** jogo." |
| "Prefiro café **do que** chá." | "Prefiro café **a** chá." |
| "Cheguei **no** escritório." | "Cheguei **ao** escritório." |
| "Vou **no** banco." | "Vou **ao** banco." |
| "O filme que assisti" | "O filme **a que** assisti" |
| "Aspiro **um** cargo." | "Aspiro **a** um cargo." |
| "Simpatizo **a** ele." | "Simpatizo **com** ele." |
| "Obedeci **as** regras." | "Obedeci **às** regras." |

### 2.2 Verbos com dupla regência e objeto pronominal

Substituição do complemento por pronome: **VTD** → *o, a, os, as*; **VTI** → *lhe, lhes* (a pessoas) — "Obedeci-**lhe**", "Informei-**o**" (mas "Assisti **a ele**" porque, no sentido de ver, não se usa *lhe*). Colocação: `12`.

## 3. Regência nominal (de memória)

Nomes que exigem preposição específica:

| Nome | Preposição | Exemplo |
|---|---|---|
| **acesso** | a | acesso **ao** sistema |
| **alusão** | a | — |
| **apto, propenso, favorável, contrário** | a, para | apto **a**/**para**; contrário **a** |
| **aversão, ódio, atração, afeição** | a, por, para, contra | aversão **a**; ódio **a**/**contra** |
| **ânsia, anseio, desejo, necessidade** | de, por | necessidade **de** |
| **atento, ávido, curioso** | a, de | atento **a**; ávido **de**/**por** |
| **capaz, incapaz** | de, para | capaz **de** |
| **compatível, incompatível** | com | compatível **com** |
| **dúvida** | sobre, acerca de, quanto a | dúvida **sobre** |
| **empenho, interesse, insistência** | em, por | empenho **em**/**por** |
| **fácil, difícil, necessário, útil** | de (+ infinitivo); para | fácil **de** entender |
| **falta, preferência** | de, por, a | falta **de** |
| **idêntico, igual, semelhante, superior, inferior, anterior, posterior** | a | superior **a**; anterior **a** (**não** "do que") |
| **impróprio, próprio, nocivo, prejudicial** | para, a | nocivo **à** saúde |
| **junto, próximo, perto, vizinho** | a, de | perto **de**; junto **a** |
| **medo, receio, temor** | de | medo **de** |
| **obediência, desobediência, respeito, lealdade** | a, com | respeito **a**/**com** |
| **responsável** | por, perante | responsável **por** |
| **residente, situado** | em | — |
| **satisfeito, contente, feliz** | com, de, por | satisfeito **com** |
| **ciente, consciente** | de | ciente **de** |

Com **pronome relativo**, a preposição do nome vem antes: "O sistema **de que** tenho acesso"? **(incorreto)** → "O sistema **a que** tenho acesso" (acesso **a**).

## 4. Regência e crase

Preposição **a** + artigo feminino *a* = **à**: "Refiro-me **à** proposta" (referir-se **a** + a proposta). Verbos que pedem **a** diante de substantivo feminino determinado → crase. Ver `11`.

## 5. Exemplo (didático)

"O diretor **aspira a** um cargo; **prefere** negociar **a** litigar; e a reunião **a que** assistiu **implicou** novos riscos." (aspirar **a**; preferir X **a** Y; assistir **a** → "a que"; implicar = acarretar, sem preposição.)

## 6. Comparações conceituais

| A | B | Diferença |
|---|---|---|
| Regência verbal | Nominal | Verbo e complemento × nome e complemento nominal |
| Objeto indireto | Complemento nominal | Complementa verbo × complementa nome |
| VTD | VTI | Sem preposição × com preposição |
| *Assistir* (ver) | *Assistir* (ajudar) | VTI (a) × VTD |
| *Aspirar* (inalar) | *Aspirar* (desejar) | VTD × VTI (a) |
| *Implicar* (acarretar) | *Implicar com* (ter implicância) | VTD × VTI |

## 7. Atenção para a prova

*Recomendação pedagógica; sem atribuir frequência à banca.*

- Verbos de **dupla regência** (*assistir, aspirar, visar, preferir, implicar, esquecer*); **preposição antes do relativo** ("a que assisti"); **chegar/ir a** (não "em").
- Não há questões de Língua Portuguesa catalogadas no projeto; nenhuma tendência é afirmada.

## 8. Síntese

Regência = relação verbo/nome e complemento. VI, VTD, VTI, VTDI, VL. Verbos de dupla regência com mudança de sentido; preposições dos relativos; regência nominal (acesso a, necessidade de, superior a); relação com crase.

## 9. Pontos para a futura produção de questões (registro)

Preposição correta; verbo com dupla regência; relativo com preposição; regência nominal; reescrita com pronome.
